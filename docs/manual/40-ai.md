# AI tools

AI in PhotoHop is optional and has strict limits: it makes **masks** (which pixels belong to something) and **settings** (colour and light values you can see and edit). It never repaints your picture, except **Remove an object**, which paints only inside that object on a separate patch layer.

## Setting up the AI tools

The AI tools are a separate Python package in the `ai` folder of PhotoHop (included in the download).

1. Install [uv](https://docs.astral.sh/uv/) (a Python installer).
2. In the `ai` folder run: `uv venv` then `uv pip install -e .`
3. For an NVIDIA graphics card, first install the CUDA build of PyTorch: `uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128`
4. In PhotoHop, open **AI > AI settings…** and enter the path of that environment's Python (for example `ai/.venv/bin/python`, or `ai\.venv\Scripts\python.exe` on Windows). You can also set the `PHOTOHOP_AI_PYTHON` environment variable.

Models download automatically the first time each tool runs. Everything works on a CPU, just slower (about 40 seconds for a photo cut-out on a laptop). Results are saved with the project, so a slower computer can keep editing without re-running AI.

## Photos

| Menu item | What it does | Model |
|---|---|---|
| Remove background | keeps the main subject of the selected layer | BiRefNet |
| Keep only… | keeps what you describe ("person", "toy gun") | SAM 3 |
| Remove an object… | erases something and fills the gap (separate patch layer) | SAM 3 + FLUX.2 klein |
| Match colours with AI | suggests how the layer should look in the scene; applied as colour sliders | Harmonizer |

### Remove an object

Type what to remove (e.g. "toy gun") in the window that opens and click **Remove**. AI fills only the object's area and the result arrives as a new layer on top — hide or delete it to undo. Keep the description neutral; describing people tends to produce invented faces.

## Video

## In the inspector

Some AI tools sit next to the settings they help: **Body-shaped shadow** and **Analyse shape** in [Shadow & light](shadow), **Measure depth** in [Camera & lens look](camera).

## Licences

Models are downloaded by you, not shipped with PhotoHop, and each keeps its own licence. Several are for non-commercial use only (MatAnyone 2, Harmonizer, some Depth Anything 3 sizes). The README lists each one.

## While AI runs

A spinner shows next to the AI buttons and the status bar reports progress. You can keep editing; the result is applied when it's ready and can be undone like any change.
