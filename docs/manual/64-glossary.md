# Glossary

| Word | Meaning |
|---|---|
| Canvas | the frame of the final picture or video: its size, frame rate and length |
| Layer | one picture, video, paint or colour sheet in the stack |
| Background | the bottom layer: the place you put things into |
| Cut-out / mask | a black-and-white picture saying which parts of a layer show (white) or hide (black) |
| Pen shape / roto | a curve-drawn shape that adds to or cuts from the mask |
| Feather | soft edge, measured in pixels |
| Composite | the combined picture of all layers |
| Colour match | setting a layer's colour sliders so it looks lit by the scene |
| Match strength | how far the colour sliders move from the original (0%) to the match (100%) |
| Temperature / tint | the colour of light: blue↔orange and green↔magenta |
| Black level | how dark the darkest parts are; hazy scenes have lifted blacks |
| Lift / Gamma / Gain | colourist names for the Shadows / Midtones / Highlights wheels |
| Curves | a graph that remaps brightness per channel |
| Qualifier | "Change one colour only": selecting colours by hue, saturation and brightness |
| Feet line / ground line | where a layer touches the ground; the shadow starts there |
| Contact shadow | the small dark patch where something touches the ground |
| Light wrap / edge light | background light spilling over the edges of a layer |
| Normal map | which way each pixel's surface faces; used by Relight |
| Depth map | how far away each pixel is; used by depth of field |
| Depth of field | blur of things nearer or further than the focus |
| Bloom | glow around bright lights |
| Grain | film or sensor noise |
| Keyframe (◆) | a value stored at a moment in time |
| Auto-key | every change adds a keyframe |
| Blend mode | the maths used to mix a layer with the ones below |
| Scopes | graphs that measure brightness and colour |
| Camera solve | working out how the camera moved in 3D during a clip |
| Bundle | the folder PhotoHop writes for Blender |
| Linear light | the physically correct way to mix light, which PhotoHop uses internally |
