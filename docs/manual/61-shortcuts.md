# Keyboard shortcuts

## Tools

| Key | Tool |
|---|---|
| V | Move |
| M | Select an area |
| C | Crop the canvas |
| B | Brush |
| E | Eraser |
| P | Pen |
| H | Hand |

## Editing

| Key | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Ctrl+D | Duplicate layer |
| Del | Delete layer (with the Pen: delete point) |
| K | Keyframe position, size, rotation and opacity |
| Enter | Crop: apply · Pen: close shape |
| Esc | Crop: cancel · Pen: finish |

## View and time

| Key | Action |
|---|---|
| Mouse wheel | Zoom towards the pointer |
| Middle-drag or Space-drag | Pan |
| Ctrl+0 | Fit canvas to window |
| Space | Play / pause |
| ← / → | Previous / next frame |
| Home | Go to start |
| S | Scopes on/off |

## Files and help

| Key | Action |
|---|---|
| Ctrl+O | Open project |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+I | Import photo / video |
| F1 | Manual |

## Modifiers

| Key | With | Does |
|---|---|---|
| Shift | Move tool corner handle | stretch freely |
| Shift | Move tool rotate handle | 15° steps |
| Shift | Select | add to the cut-out |
| Alt | Select | subtract from the cut-out |
| Alt | Pen handle | break the curve into a corner |

In the web version of this manual, press **/** to jump to the search box.
