# Menus

## File

| Item | Does |
|---|---|
| New project | empty project: 1920×1080, 1080×1920, 4K or 4K vertical |
| Open… (Ctrl+O) | open a `.phop` project |
| Save (Ctrl+S) / Save as… | save the project |
| Import photo / video… (Ctrl+I) | add pictures or clips as layers |
| Export… | export the current frame or the timeline; see [Saving & exporting](export) |
| Export to Blender… | write a bundle for the PhotoHop Bridge add-on; see [Blender round trip](blender) |
| Import Blender render… | bring Blender renders back as layers |

## Edit

Undo and Redo. The Undo item names what it will undo.

## Layer

| Item | Does |
|---|---|
| Import photo / video… | same as File > Import |
| New paint layer | empty layer to paint on |
| New colour layer | one flat colour |
| Duplicate (Ctrl+D) / Delete (Del) | copy or remove the selected layer |
| Remove background (AI) | cut-out of the selected layer |
| Split into separate objects | one layer per object; see [Several objects in one picture](several-objects) |
| One-click fit into the scene | colour match + shadow + grain; see [Fit into the scene](fit) |

## AI

Grouped into **Photos**, **Video** and **For Blender**, plus **AI settings…** (which Python has the AI tools). See [AI tools](ai).

## View

| Item | Does |
|---|---|
| Scopes (S) | waveform, parade, vectorscope, histogram |
| Fit to window (Ctrl+0) / 100% | zoom |
| Video preview quality | Full, Half (default) or Quarter |

## Help

The manual (F1), the first-composite walk-through, keyboard shortcuts, and the manual in your web browser.
